# ChimeraBoostClassifier

Gradient boosted oblivious trees for classification. Binary log loss for 2 classes,
softmax for 3 or more, chosen automatically. See the User Guide:
[multiclass](../recipes.md#multiclass-classification) and
[calibrated probabilities](../recipes.md#calibrated-probabilities).
